# Arizona Helper — автоматическое облако

Начните с **AUTOMATION-RU.md**. В нём описаны установка GitHub Actions/Pages, ограничения и результаты проверок.

В отличие от предыдущей ручной сборки, адреса 33 ПК-серверов уже сопоставлены автоматически, настроено расписание сборщика, экспорт версий и публикация сайта. Автоматизация подготовлена в коде, но на внешнем хостинге пока не запущена.

SQLite хранится в `data/rules.sqlite3.gz`; для локальной работы восстановите его командой из инструкции. Python `manage.py` и автоматизация используют SQLite как источник; публично публикуется только JSON-каталог. Ни секретов, ни настроек игроков в базе нет.
