# Arizona Helper — единое облако правил

Облако опубликовано: https://budhachgjndon.github.io/arizona-helper-cloud/

Игрокам не нужны GitHub-аккаунт, ручные IP-таблицы и настройка ссылок. Helper PC 0.3.1 содержит адрес сайта и автоматически проверяет версии пакетов каждые 15 минут. Код Lua из облака не исполняется.

## Проверенный результат первой публикации

- 36 серверных разделов, 712 сохранённых документов, 3571 сообщение.
- 33 ПК-сервера сопоставлены по номеру/имени API лаунчера и DNS, создано 66 привязок доменов/IPv4. Mobile пока не привязан для автоматического клиента.
- Все 66 JSON-пакетов и 66 файлов версий проверены по HTTPS, SHA-256-маркеру версии и настоящему Lua-валидатору Helper.
- GitHub Actions: build и deploy прошли; расписание обновления — каждые 6 часов.

## Ограничения

Первый выпуск опубликован из сохранённого сбора, без нового чтения форума. Тексты **unreviewed**: это справочные материалы, а не подтверждённый действующий полный свод. Исходный сбор преимущественно с первых страниц; изображения и внешние документы могут отсутствовать. Автоматическое утверждение/выдача наказаний не выполняется.

Обычный HTTP-сбор получил страницу проверки браузера. В расписании предусмотрен обычный браузерный режим, но успешное обновление правил через него пока не подтверждено. Если источник откажет, прежние данные сохраняются и публикуется отчёт об ошибке. Гарантии беспрерывного доступа к форуму нет. Обход следующих страниц существующих тем ограничен 40 страницами; поиск новых тем — первыми страницами известных разделов, не всем форумом.

В GTA новый клиент ещё не тестировался. Отдельного просмотра армейского каталога в игровом интерфейсе пока нет; полные материалы доступны на сайте.

## Эндпоинты

- `index.json` — каталог;
- `servers/<id>.json` — полные сохранённые документы;
- `rules/<address_port>.json` — пакет клиента;
- `rules/<address_port>.version.json` — версия;
- `status.json`, `checks.json` — состояние источников.

Код базы/сборщика: manage.py и automation/pipeline.py. SQLite хранится сжатым в data/rules.sqlite3.gz. Паролей, cookies и игровых настроек в репозитории нет. AUTОMATION-RU.md описывает воспроизведение развёртывания; шаги создания сайта уже выполнены для этого репозитория.
